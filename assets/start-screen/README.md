# Assets — Ao Trabalho

Camada inicial independente do hub atual.

- `brand-logo.svg`: marca horizontal Ao Trabalho.
- `empty-courtyard.svg`: cenário-base limpo; a área central é reservada aos slides conceituais.
- `menu-buttons.svg`: prancha de referência dos botões. A interface usa botões HTML independentes para acessibilidade e ações reais.

Os SVGs são assets editáveis e separados. A camada de entrada é apresentada antes da abertura legada; o fluxo PilhA+ original permanece preservado após selecionar Jogar.
