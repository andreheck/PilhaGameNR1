# Investment budget and forecasts

Each browser starts with 10,000 fictional credits. A floating welcome alert leads to the Investments screen. Balance and purchases persist in localStorage only and are not synchronized between devices.

Available upgrades: Ergonomics (1,800); Breaks and shift coverage (1,200); Listening channel (900); Team capacity (3,200); Leadership training (1,500); Layout and circulation (2,100). Each card shows an educational 30-day forecast and synthetic indicator effects. The purchase system blocks duplicate purchases and overspending, stores a history, and updates the sector appearance. Purchased upgrades are restored on reload.

Automated tests are in `tests/investment-system.test.mjs`; run `npm test`. Forecasts are deterministic educational scenarios, not financial estimates or clinical predictions. Current visual effects use sector color and an installation ring; more specific 3D objects and real browser QA remain future work. No production deployment or merge is authorized by this PR.
